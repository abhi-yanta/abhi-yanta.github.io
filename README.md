# Abhinav Jaiswal | Portfolio

Personal portfolio built with React, Three.js, GSAP and Tailwind CSS.

Based on the MIT-licensed [threejs-portfolio](https://github.com/sanidhyy/threejs-portfolio) template by Sanidhya Kumar Verma (see `LICENSE`).

## Run locally

```bash
pnpm install
pnpm dev
```

## Content

All text lives in `src/constants/index.ts`, plus the About section in `src/sections/About.tsx`.

## Contact form (optional)

The form runs on a Netlify function using Resend. Set `RESEND_API_KEY`, `RESEND_FROM_EMAIL` and `CONTACT_TO_EMAIL` in your Netlify environment variables.
